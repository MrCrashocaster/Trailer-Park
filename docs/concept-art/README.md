# Concept art

These images were generated as design references during the project discussion. They are **concept art/mockups, not renders of the current asset files or screenshots of running gameplay**. Use actual asset previews to judge what has already been modeled. The images suggest atmosphere and workflows; incidental object placement, floor-plan details and printed UI values are not binding specifications.

| File | Purpose | Status / caveat |
| --- | --- | --- |
| [grounded-park-mood.png](grounded-park-mood.png) | Ordinary overcast afternoon, shabby inhabited trailers, small shady deal and neighborhood friction. | User accepted this atmospheric direction. |
| [trailer-interior-layout.png](trailer-interior-layout.png) | Cutaway interior concept with clear hallway beside the refrigerator. | Revised after a blocked hallway was identified. The actual Blender interior is an adaptation, not an exact match. |
| [park-management-overview.png](park-management-overview.png) | Six lots, office, gravel lane, selected supervisor, roof-hidden interior and simple management UI. | Proposed achievable direction; vegetation detail and finished lighting/UI exceed the current prototype state. |
| [park-life-home-building.png](park-life-home-building.png) | Three proposed modes: complaints/park interactions, home life, grid-based lot placement. | All gameplay and UI shown remain proposed. |

No user-supplied actor photograph is included in this directory. The project should develop an original character identity rather than reproduce actors, costumes, catchphrases or branding.
